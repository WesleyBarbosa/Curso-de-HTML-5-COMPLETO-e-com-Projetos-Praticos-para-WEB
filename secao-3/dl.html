Exemplo de uso da tag dl:

HTML
Uma linguagem de marcação usada para criar páginas web.
CSS
Uma linguagem de estilo usada para descrever a apresentação de documentos HTML.
JavaScript
Uma linguagem de programação usada para criar conteúdo interativo em páginas web.

Neste exemplo, a tag <dl> é usada para criar uma lista de descrição com termos (<dt>) e suas definições (<dd>).
